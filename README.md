# PC Island

Une « Dynamic Island » pour Windows, en encoche en haut de l'écran :
musique en cours + paroles, WhatsApp (favoris, messages, appels), horaires de prière (Alger).

**Installer :** télécharge `PC-Island.zip` dans la dernière [release](../../releases/latest),
dézippe, lance `PC Island.exe`. Les mises à jour suivantes se font avec le bouton
« Mettre à jour » dans l'île.
